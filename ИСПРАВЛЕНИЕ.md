# Исправление: Сохранение графика смен с фильтрами

## Проблема (которую мы исправили)

Когда вы:
1. Фильтровали график по отделу
2. Меняли значения (б, кп, д, н, от, п) для сотрудников
3. Нажимали сохранить

Система писала "Сохранено", но при обновлении страницы или отключении фильтра данные были в **неправильных строках** - у других сотрудников!

### Пример проблемы:
```
1. Фильтр: Отдел "1"
2. Иван: установите "б" (болничный)
3. Сохраните
4. Обновите страницу (или отключите фильтр)
5. ❌ "б" появилось у Петра, а не у Ивана!
```

## Причина проблемы

В коде была ошибка в обработке названий столбцов дней (день 01, 02, 03, ..., 31).

**На странице (форма)**: названия ячеек = `cell_2_01`, `cell_2_02` (со строками "01", "02")

**В сохранении (ДО исправления)**: система искала `cell_2_1`, `cell_2_2` (с числами 1, 2)

Это не совпадает! Поэтому система не находила данные для сохранения.

## Исправление

Мы изменили код, чтобы **везде** использовались строковые названия столбцов (как на странице).

### Что изменилось:

**Было (неправильно)**:
```python
for d in day_columns:
    key = f"cell_{i}_{d}"                    # ❌ d как число
    ...
    full_schedule_df.at[full_idx, d] = raw   # ❌ d как число
```

**Стало (правильно)**:
```python
for d in day_columns:
    col_key = str(d)                              # ✅ Преобразуем в строку
    key = f"cell_{i}_{col_key}"                  # ✅ col_key как строка
    ...
    full_schedule_df.at[full_idx, col_key] = raw # ✅ col_key как строка
```

## Результат

Теперь **все работает правильно**:
- Форма ищет: `cell_2_01`
- Сохранение ищет: `cell_2_"01"`
- ✅ Они совпадают!
- ✅ Данные сохраняются в правильные строки!
